# Contributing to AI Code Review Assistant

We love your input! 🎉  
By contributing, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/your-username/code-review-ai.git`
3. Create a branch: `git checkout -b feature/your-idea`
4. Make your changes and commit them: `git commit -m 'Add some feature'`
5. Push to the branch: `git push origin feature/your-idea`
6. Open a Pull Request.

## Development Guidelines

- Write clean, modular Python code.
- Follow PEP 8 style guide.
- Add docstrings to new functions (Google style).
- Keep `requirements.txt` up to date.
- Test locally before submitting.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer.
2. Update the `README.md` with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. Increase the version numbers in any examples files and the `README.md` to the new version that this Pull Request would represent.
4. You may merge the Pull Request in once you have the sign-off of one other developer, or if you do not have permission to do that, you may request the reviewer to merge it for you.

Please note we have a Code of Conduct; follow it in all your interactions with the project.
